```
                    /\
                   /  \
                  /    \
                 / E2E  \
                /  Tests \
               /----------\
              /            \
             /              \
            /  Integration   \
           /      Tests       \
          /--------------------\
         /                      \
        /                        \
       /       Unit Tests         \
      /                            \
     /______________________________\

```

## Описание уровней:

### Unit Tests (Модульные тесты)
- **Количество**: Максимальное (70-80%)
- **Скорость**: Очень быстрые (миллисекунды)
- **Стоимость**: Низкая
- **Примеры**: 
  - ScoringServiceTest
  - InnValidatorTest
  - BankAccountValidatorTest

### Integration Tests (Интеграционные тесты)
- **Количество**: Среднее (15-20%)
- **Скорость**: Средняя (секунды)
- **Стоимость**: Средняя
- **Примеры**:
  - ApplicationTests (Spring Context)
  - Repository Tests с реальной БД
  - API Integration Tests

### E2E Tests (Сквозные тесты)
- **Количество**: Минимальное (5-10%)
- **Скорость**: Медленные (минуты)
- **Стоимость**: Высокая
- **Примеры**:
  - Полный сценарий создания договора
  - Процесс скоринга клиента
  - Регистрация платежей

## Соотношение тестов в проекте LeaseManager:

| Тип теста | Количество | Процент |
|-----------|------------|---------|
| Unit      | 45         | 75%     |
| Integration| 12        | 20%     |
| E2E       | 3          | 5%      |
| **Всего** | **60**     | **100%**|
